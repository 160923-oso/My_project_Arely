## Aplicación Streamlit de Análisis de Datos de Anuncios de Venta de Coches
Esta aplicación de Streamlit proporciona una exploración interactiva de un conjunto de datos de anuncios de venta de coches. Permite a los usuarios visualizar y analizar diferentes aspectos de los datos, incluyendo la distribución de precios, modelos, años y condiciones de los coches.

## Funcionalidades
La aplicación ofrece las siguientes funcionalidades:

Visualización del conjunto de datos: Muestra el conjunto de datos completo en una tabla interactiva utilizando st.dataframe(), permitiendo a los usuarios explorar los datos directamente en la aplicación.

Histograma de Kilometraje: Crea un histograma interactivo que muestra la distribución del kilometraje de los coches, con la opción de segmentar los datos por modelo.

Gráfico de Dispersión Modelo vs. Precio: Genera un gráfico de dispersión que visualiza la relación entre el modelo del coche y su precio, permitiendo a los usuarios identificar posibles tendencias o valores atípicos.

Histograma de Año del Modelo y Condición: Muestra un histograma que representa la distribución de los años de los modelos de los coches, segmentados por su condición.

Gráfico de Dispersión de Condiciones de los Coches: Crea un gráfico de dispersión que ilustra la relación entre la condición de los coches y sus precios.

Gráfica Circular de Tipos de Coches: Muestra la distribución de los diferentes tipos de coches en el conjunto de datos.

## Cómo usar la aplicación
Asegúrate de tener instalado Python y Streamlit.

Coloca el archivo vehicles_us.csv en el mismo directorio que el script de Python.

Ejecuta la aplicación usando el comando streamlit run tu_script.py.

La aplicación se abrirá en tu navegador web.

Explora las diferentes visualizaciones y características interactivas para analizar los datos de anuncios de venta de coches.
